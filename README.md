# WindowMerger

Приложение для Windows, которое показывает окна приложений со всех подключённых экранов и переносит выбранное окно в центр следующего экрана двойным щелчком.

Если экран один, окно перемещается в центр этого же экрана.

## Возможности

- Общий список открытых окон, включая свёрнутые и окна без заголовка.
- Для каждого окна показаны название, экран, положение и размер, процесс и PID.
- Перенос двойным щелчком по строке или клавишей Enter для выбранной строки.
- Обновление списка кнопкой «Обновить» и после попытки переноса.
- Восстановление свёрнутых и развёрнутых окон перед центрированием.
- Сообщения об ошибках, если окно закрыто, недоступно или не отвечает.
- Светлая и тёмная темы в соответствии с настройками системы.

## Как пользоваться

1. Запустите WindowMerger.
2. Найдите нужное окно в списке. Наведите указатель на обрезанный текст, чтобы увидеть его полностью.
3. Дважды щёлкните по строке окна. Можно также выбрать строку и нажать Enter.
4. При открытии или закрытии других приложений нажмите «Обновить».

Экраны упорядочены по их расположению в виртуальном рабочем столе: слева направо, а при одинаковой горизонтальной координате сверху вниз. После последнего экрана выбирается первый. Номера в приложении могут отличаться от номеров в настройках Windows.

Центр вычисляется по рабочей области экрана, без панели задач. Размер обычного окна сохраняется; при переходе между экранами с разным масштабированием Windows может изменить его размер. Приложение повторно центрирует окно с учётом фактических размеров. Окно, которое больше рабочей области, центрируется без принудительного уменьшения.

## Требования

- Windows 10 или Windows 11.
- [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0) для сборки из исходников.
- Подключение к интернету при первом восстановлении NuGet-пакетов.

Интерфейс написан на Avalonia 12, работа с чужими окнами реализована через Win32 API. Перенос окон доступен только в Windows.

## Сборка и запуск

В PowerShell:

```powershell
git clone https://github.com/Knjaz2005/WindowMerger.git
cd WindowMerger
dotnet build WindowMerger.csproj -c Release
dotnet run --project WindowMerger.csproj -c Release --no-build
```

После сборки приложение также можно запустить файлом `bin\Release\net10.0\WindowMerger.exe`. Для этой сборки на компьютере должен быть установлен .NET 10 Runtime либо SDK.

## Сборка без установленного .NET у пользователя

Чтобы собрать автономную версию для Windows x64:

```powershell
dotnet publish WindowMerger.csproj -c Release -r win-x64 --self-contained true -o publish/win-x64
```

Для распространения нужна вся папка `publish\win-x64`, включая библиотеки. Точка запуска: `WindowMerger.exe`. Для Windows ARM64 замените `win-x64` на `win-arm64`.

## Ограничения

- Список содержит пользовательские окна текущего рабочего стола, включая свёрнутые. Скрытые служебные окна, панели задач, неактивируемые наложения и скрытые Windows окна других виртуальных рабочих столов не включаются.
- Свёрнутое или развёрнутое окно после переноса становится обычным окном.
- Приложения с повышенными правами могут запретить перенос из обычного процесса. Для работы с ними WindowMerger может потребоваться запустить с теми же правами.
- Некоторые приложения сами ограничивают положение окна. В таком случае WindowMerger сообщает, что центрирование не подтверждено.

## Проверка

Проверены сборка Release и работа на одном подключённом экране: перечисление окон, двойной щелчок, центрирование, сохранение размеров, восстановление свёрнутых и развёрнутых окон, обработка закрытого окна и щелчка по пустому месту списка.

Порядок перехода между несколькими экранами, возврат с последнего на первый и расчёт координат для экранов с отрицательными координатами проверены на моделируемых конфигурациях. Проверка на физических мониторах с разным DPI не проводилась.
